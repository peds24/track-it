Material 3 Design Specification

Design tokens, typography scales, surface elevation roles, and gesture physics for Track It.

1. Color Roles & Palette

Track It uses official Material 3 tonal color roles with dynamic contrast and surface containers.

Primary Key CTAs, Add buttons, active highlights
Primary Container Edit action container, selection fills
Secondary Container Tab active pill, Pause / Backlog actions
Error Container Delete action container, destructive alerts
Surface Container Navigation bar background, dialog surfaces
Surface Container High Category badges, count chips, pill badges

2. Google Sans 15-Tier Typography Scale

Standardized on the Google Sans typescale across Display, Headline, Title, Body, and Label roles.

Role Size / Line Height Weight Usage in Track It
Headline Medium 28sp / 36sp 700 (Bold) Screen title headers (Currently, Backlog, Done)
Category Subtitle 19sp / 26sp 700 (Bold) Section subtitles (Shows, Movies, Books)
Title Medium 16sp / 24sp 500 (Medium) Track item title rows (Severance, The Matrix)
Label Large 14sp / 20sp 700 (Bold) Button labels (+ Add, Done, Start)
Label Medium 12sp / 16sp 700 (Bold) Swipe action labels, section counts, active tab labels
Label Small 11sp / 14sp 700 (Bold) Medium badges (SHOW, MOVIE, BOOK, MANGA)

3. 2-Step Gesture Physics & Swipe Mechanics

Right Swipe (Backlog / Pause → Delete)

  • 0 to 28dp: Slop zone (treats gesture as vertical scroll).
  • 28dp to 175dp (Quick Swipe): secondaryContainer background, reveals pause-circle / bookmark icon. Releasing immediately triggers Pause / Move to Backlog.
  • ≥ 175dp (Deep Pull): Smoothly morphs background to errorContainer, scales trash icon with pop animation, and prompts Delete confirmation on release.

Left Swipe (Progress Editor)

  • ≥ 40dp (Quick Left Swipe): primaryContainer background, reveals create pencil icon. Releasing immediately opens the Episode/Volume/Issue Progress Editor dialog.

4. Shape Scale & Containers

  • Pill / Round (radius.full / 9999dp): Primary buttons, navigation tab active indicators, count chips.
  • Medium (radius.md / 12dp): Empty state cards, dialog surfaces, modal pickers.
  • Small (radius.xs / 4dp): Category icon badges, medium chips.
