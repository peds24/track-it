# Iris I0 — Foundations Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An empty but real native iOS project in `apple/`: an `IrisCore` Swift package and an `Iris` SwiftUI app that build, test and launch in the iOS simulator from one command, merged into the `iris` branch.

**Architecture:** `IrisCore` is a local Swift package (logic only, no UI imports) that `swift test` can run on the Mac without a simulator. The `Iris` app target and its UI tests are described by `apple/project.yml` and generated by `xcodegen`. The `.xcodeproj` is never committed. A single script, `apple/scripts/test.sh`, regenerates the project and runs both suites.

**Tech Stack:** Swift 6.4 toolchain (language mode 6), SwiftUI, XCTest, xcodegen (`/opt/homebrew/bin/xcodegen`), Xcode 27.0, iOS 26.2 simulator runtime.

**Spec:** `docs/superpowers/specs/2026-10-06-iris-design.md` (§2.1 layout, §2.2 Swift choices, §8 step I0, §10 testing).

**Already done on this branch (`worktree-iris-foundations`):** the spec, amendment A28, the CLAUDE.md §6 `iris` row, the HANDOFF entry, ROADMAP pointers, and a sync merge of `android` at `276375c`. This plan covers the rest of I0.

## Global Constraints

- iOS deployment target **26.0**; Swift language mode **6** with complete strict concurrency.
- `IrisCore` must not import SwiftUI or UIKit (spec §2.1: "`IrisCore` does no UI").
- Only `apple/project.yml` is committed; `apple/Iris.xcodeproj` is generated and git-ignored (spec §2.2).
- API keys live in a git-ignored `Secrets.xcconfig`; a committed `Secrets.example.xcconfig` documents the names (spec §2.2).
- Proposed bundle ID `com.peds24.iris` (spec §7; final decision in I11).
- Default simulator: `iPhone 17` (installed, iOS 26.2), overridable.
- Nothing in the TS app changes: `npm run typecheck` and `npm test` (550 tests) stay green.
- Never commit directly to `iris`. Finish by merging `worktree-iris-foundations` into `iris` with `--no-ff` (CLAUDE.md §6).
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` (substitute the model in use).

- [ ] **Step 1: Write the script**

`apple/scripts/test.sh`:

```bash
#!/usr/bin/env bash
# Iris native test runner: regenerate the Xcode project, run IrisCore's
# tests on the Mac, then the app's UI tests on an iOS simulator.
#   apple/scripts/test.sh              # everything
#   apple/scripts/test.sh --core-only  # IrisCore only (no simulator)
#   IRIS_SIM="iPhone 17 Pro" apple/scripts/test.sh
set -euo pipefail

APPLE_DIR="$(cd "$(dirname "$0")/.." && pwd)"
SIM="${IRIS_SIM:-iPhone 17}"

command -v xcodegen >/dev/null || { echo "xcodegen not found — brew install xcodegen" >&2; exit 1; }

echo "▸ IrisCore (swift test)"
swift test --package-path "$APPLE_DIR/IrisCore"

[[ "${1:-}" == "--core-only" ]] && exit 0

if ! xcrun simctl list devices available | grep -q "    $SIM ("; then
  echo "Simulator \"$SIM\" is not installed. Available iPhones:" >&2
  xcrun simctl list devices available | grep -E "^\s+iPhone" | sed -E 's/ \(.*//' >&2
  echo "Set IRIS_SIM to one of these." >&2
  exit 1
fi

echo "▸ Generating Iris.xcodeproj"
xcodegen generate --spec "$APPLE_DIR/project.yml" --project "$APPLE_DIR" --quiet

echo "▸ Iris UI tests on $SIM"
xcodebuild test \
  -project "$APPLE_DIR/Iris.xcodeproj" \
  -scheme Iris \
  -destination "platform=iOS Simulator,name=$SIM" \
  -derivedDataPath "$APPLE_DIR/DerivedData" \
  -quiet
echo "✓ All Iris tests passed"
```

Then: `chmod +x apple/scripts/test.sh`
